# Reading Profile

This sample targets short, reflowing explanatory text. It defines no control
behavior, screen density, print pagination, or corporate identity.

Use the [paragraph gap](../../foundation/spacing.tokens.json) as an illustrative
default between adjacent paragraphs. The [HTML adapter](../../adapters/html/INTEGRATION.md)
provides a scoped CSS counterpart. The profile requires no other profile, and no
multi-profile combination is claimed by this example.

For the optional terminology demonstration, write **Example Device**, not
**ExampleDevice**. The [Vale rule](../../validation/vale/styles/Example/Terminology.yml)
encodes that spelling. This is a synthetic test rule, not a proposed writing voice.

An actual reading profile would establish typography, responsive behavior,
hierarchy, and accessibility requirements with real examples. This fixture does
not pretend that those decisions have been made.
